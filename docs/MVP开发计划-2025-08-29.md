# 植道 ZhiDao - MVP 开发计划（2025-08-29）

## 一、项目现状分析（基于仓库与记录核对）
- 路由与页面（app.json）：pages/index、pages/quiz/step（动态问卷入口）、pages/question（传统问卷）、pages/result、pages/detail；usePrivacyCheck 已开启。
- 全局初始化（app.js）：按抖音小程序规范使用 tt.createCloud(envID, serviceID)，login/checkSession，globalData 存储 cloud/状态。
- 前端能力：
  - 动态问卷（pages/quiz/step）：支持从 /getQuestionConfig 获取 questionBank（v2.2 ≈25题），具备本地缓存与降级；自适应问卷占位（稳定度估计/追加题/停止规则）；多选题 UI 待补。
  - 推荐结果（pages/result）：MMR+不确定性惩罚后端结果的前端展示；已集成 PlantNet 图片资源的智能显示与降级；限制最多5条、隐藏评分字样、展示推荐理由。
  - 详情页（pages/detail）：可通过 /getPlantDetail 展示更丰富百科信息及安全提示。
  - 埋点（utils/analytics.js）：已有 start_question、question_next、adaptive_extra、adaptive_finish 等占位事件。
- 后端服务（server/zhidao-api）：
  - 接口：/healthz、/getQuestionConfig（GET/POST，含数据库与文件回退）、/debugQuestionConfig、/listPlants、/recommendPlants（支持 MMR+不确定性惩罚+AB 分桶 debug）、/submitAnswers、/importData、/getPlantDetail。
  - 数据：question_config 已导入 v2.2（supportsDynamicQuestionnaire=true），plants≥5；支持 /importData 一键导入。
  - 性能与一致性：listPlants/recommendPlants 仍偏向“全量拉取+内存过滤”；/getQuestionConfig 的 GET/POST 查询条件存在差异，建议统一。
- 工具链与文档：scripts/offline_eval（评估骨架）、A/B 分桶与回滚指引、埋点指标与看板字典、PlantNet 图片下载与上传脚本齐备。
- 技术栈与平台：抖音小程序端（tt.* API、ttml/ttss）、抖音云容器服务 + 云数据库（dySDK.database()）、Node.js（Express 风格服务）、本地脚本 Node/JS。

## 二、MVP 功能规划
- 目标：在保持当前可用链路的基础上，补齐“动态问卷多选题 + 后端查询一致性与性能 + 埋点看板 + 合规配置”，完成可灰度的最小可用闭环。
- 功能清单（按优先级）：
  - 高
    1) 前端多选题 UI/交互与答案序列化（pages/quiz/step）
    2) 后端 /getQuestionConfig 查询逻辑统一（GET/POST 共用查询函数）
    3) 后端 listPlants/recommendPlants 改为 DB 侧筛选 + 分页（核对索引）
    4) Dev 环境 AB 配置验证（AB_MODE=hash、ENABLE_BAYES_UNC/MMR 等）
  - 中
    5) 埋点完善与看板联动（前端每题耗时/追加题/降级；后端P50/P95/MMR耗时/fallback率）
    6) 离线评估脚本完善（NDCG/ILAD/多样性、参数网格、CSV/JSON 输出）
  - 低
    7) 合规与配置自查（navigateToMiniProgramAppIdList、第三方跳转声明、隐私政策链接与 usePrivacyCheck）

- 复杂度与工时预估（相对：S≤0.5d，M≈0.5–1d，L>1d）：
  - 多选题 UI/交互：M（0.5–1 天）
  - /getQuestionConfig 统一：S（0.5 天）
  - DB 侧筛选 + 分页 + 索引核对：M（0.5 天）
  - Dev AB 配置验证：S（1–2 小时，需控制台权限）
  - 埋点与看板完善：M（0.5 天）
  - 离线评估完善：M（0.5–1 天）
  - 合规与配置自查：S（0.5 天）

- 依赖关系与顺序：
  1) /getQuestionConfig 统一 与 多选题 UI 可并行；
  2) DB 侧筛选需配合云端索引核对（需控制台操作）；
  3) AB 验证依赖后端已发布和环境变量；
  4) 埋点看板与离线评估可并行推进；
  5) 合规自查可与测试阶段并行。

## 三、开发方案与任务拆解（含验收标准）
1) 多选题 UI/交互（pages/quiz/step）
   - 内容：支持 checkbox 型题目，选项多选与取消、进度计算、答案结构序列化与提交兼容；动态触发逻辑不受影响。
   - 验收：
     - 能正确显示多选题并选择/取消；
     - 本地缓存与恢复正常；
     - submit 后后端可解析，结果页正常；
     - 真机调试通过，无报错；
     - 基础库/弱机下仍流畅（P95 切题≤50ms）。

2) /getQuestionConfig 查询逻辑统一
   - 内容：抽取统一查询函数，GET/POST 共用；兼容 questionBank | config.questions | questions 多路径；返回 supportsDynamicQuestionnaire。
   - 验收：
     - GET 与 POST 返回一致（除方法差异外）；
     - 当 DB 无匹配时走文件回退；
     - 新老字段兼容；
     - 单测/契约测试通过。

3) listPlants/recommendPlants 查询优化
   - 内容：DB 侧条件（onShelf、tags、safetyFlags 等）+ 分页；校验/创建索引：plants(onShelf,tags,updatedAt)。
   - 验收：
     - 接口 P95 ≤ 800ms（dev）；
     - 返回数量与分页正确；
     - 与旧逻辑结果一致或更优；
     - riskFlags(few_candidates/slow_endpoint) 降低。

4) Dev AB 配置验证
   - 内容：在 dev 环境设置 AB_MODE=hash、ENABLE_BAYES_UNC=1、ENABLE_MMR=1 等并发布；接口调试验证 /recommendPlants debug.ab、elapsed、mmrCostMs。
   - 验收：
     - debug.ab.bucket 正常分布；
     - 启用/关闭开关时结果与耗时符合预期；
     - 出现异常可一键关闭开关回滚。

5) 埋点与看板完善
   - 内容：前端每题耗时/追加题/降级事件；后端 rec_* 时延、MMR耗时、fallback 命中率；看板阈值与降级策略。
   - 验收：
     - 关键事件采集完整无重复；
     - 看板可展示 P50/P95、fallback率、安全曝光率；
     - 超阈值触发自动降级（关闭 ENABLE_* 或回退 fast）。

6) 离线评估脚本完善
   - 内容：补全 NDCG@5/10、ILAD、多样性；参数网格/贝叶斯；CSV/JSON 输出；对接 debug 配置。
   - 验收：
     - 能读取样例数据并输出评估报告；
     - 网格寻优输出 top5 参数组合；
     - 与线上趋势基本一致（用于相对比较）。

7) 合规与配置自查
   - 内容：隐私政策展示/usePrivacyCheck；第三方跳转声明与 navigateToMiniProgramAppIdList；图片域名白名单/CDN；GET 不带 body；用户隐私授权弹窗（24h不打扰策略）。
   - 验收：
     - 规范项 checklist 全部通过；
     - IDE 预检与提审校验无阻塞项。

## 四、时间计划（假设1人日）
- D0：输出本计划、创建任务清单、与干系人确认（当天）
- D1：多选题 UI/交互（并行：/getQuestionConfig 统一）
- D2：DB 侧筛选 + 分页 + 索引核对；Dev AB 验证
- D3：埋点与看板完善 + 离线评估脚本
- D4：合规自查 + 回归测试 + 预发/体验版

## 五、测试与验收策略
- 前端：单测/集成（动态问卷流程、多选题序列化、结果页展示）；真机调试（弱网/低端机）；
- 后端：契约测试（/getQuestionConfig、/listPlants、/recommendPlants、/submitAnswers）；接口 P95 观测；
- E2E：问卷→推荐→详情全链路；AB 小流量灰度；
- 验收门槛：功能通过 + 性能达标 + 合规通过。

## 六、风险与回滚
- 完成率下滑：提高 VOI 阈值、限制追加题≤3、默认 fast 模式；
- 时延抖动：降低 Top-M、关闭 ENABLE_MMR/ENABLE_BAYES_UNC、结果降级；
- 数据兼容：统一查询函数 + 文件回退；
- 云端环境：任何异常可回滚至上一版本并关闭开关。

## 七、后续扩展（非 MVP）
- 详情页图片轮播与放大；更多 PlantNet 图片接入；
- 自适应问卷强化（本地MC采样与停止规则优化）；
- 学术化推荐（xQuAD、多目标、多样性重排），配合离线评估与 A/B。
